---
slug: mental-model
name:
  en: Mental model
  ko: 멘탈 모델
definition:
  en: >-
    What the user believes about how the thing works — not what it does, and not
    what the documentation says. It governs what they expect a control to do,
    and it is what an interface has to answer to whether or not it is accurate.
  ko: >-
    사용자가 이것이 어떻게 작동한다고 믿고 있는 내용. 실제 동작도 아니고 문서에
    적힌 설명도 아니다. 어떤 조작 장치가 무엇을 할 것이라 기대하는지를 좌우하며,
    정확하든 아니든 인터페이스가 상대해야 하는 것은 바로 이 모델이다.
justification:
  en: >-
    [Control] behaves the way the system thinks about itself, not the way [the
    reader] would expect. They would predict [what], so matching the expectation
    is a safer change than explaining it away in a tooltip.
  ko: >-
    [조작 장치], 이건 시스템이 스스로를 이해하는 방식대로 동작하고,
    [읽는 사람]이 예상하는 방식대로 동작하지 않습니다. 이들이 예상하는
    것은 [무엇]이므로, 툴팁으로 무마하기보다 그 예상에 맞추는 편이
    안전한 변경입니다.
