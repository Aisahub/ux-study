---
slug: sense-of-place
name:
  en: Sense of place
  ko: 현재 위치 감각
definition:
  en: >-
    Being able to answer, without scrolling or guessing, where you are and how
    you got here. A flow that never says which step this is out of how many
    leaves the user unable to judge whether it is worth finishing.
  ko: >-
    스크롤하거나 짐작하지 않고도 지금 어디에 있는지, 어떻게 여기까지 왔는지
    답할 수 있는 상태. 전체 몇 단계 중 지금이 몇 번째인지 말해 주지 않는
    플로우는, 끝까지 갈 만한 일인지 사용자가 판단할 수 없게 만든다.
justification:
  en: >-
    [Step] never says which step of how many it is, so the user cannot tell
    whether they are nearly done or barely started. Stating the position would
    let them decide whether to carry on.
  ko: >-
    [단계], 이건 전체 몇 단계 중 몇 번째인지 말해 주지 않아서,
    사용자는 거의 끝난 건지 이제 시작인지 알 수 없습니다. 위치를 밝혀
    주면 계속할지 말지 스스로 정할 수 있습니다.
competencies:
  - way-back-and-control
