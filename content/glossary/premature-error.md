---
slug: premature-error
name:
  en: Premature error
  ko: 때 이른 오류
definition:
  en: >-
    An error raised before the user has finished saying what they meant — a
    field marked wrong while it is still being typed into. It is not early help;
    it is the interface telling someone they are failing at something they are
    still in the middle of doing.
  ko: >-
    사용자가 입력을 다 마치기도 전에 띄우는 오류. 아직 입력 중인 칸에 벌써 틀렸다고 표시하는 것. 미리 돕는 것이 아니라, 아직 하고 있는 일을 두고 실패했다고 말하는 것이다.
justification:
  en: >-
    [Field] turns red while the user is still typing into it, so it calls a
    half-finished entry a mistake. Waiting until they leave the field would keep
    the check and drop the accusation.
  ko: >-
    [칸], 이건 사용자가 아직 입력하는 중에 빨갛게 바뀌어서, 절반쯤
    쓴 값을 벌써 틀린 값으로 취급합니다. 사용자가 다른 칸으로 넘어갈 때까지 기다리면 검사는 그대로 두고 나무라는 부분만 없앨 수 있습니다.
competencies:
  - error-handling
source: https://www.nngroup.com/articles/hostile-error-messages/
