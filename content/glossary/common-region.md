---
slug: common-region
name:
  en: Common region
  ko: 공통 영역
definition:
  en: >-
    A shared border or background makes the elements inside it read as one
    group, even where spacing alone would not. Use it when white space is not
    enough — it adds visual clutter, so it is spent sparingly.
  ko: >-
    같은 테두리나 배경 안에 있으면 그 안의 요소들이 한 그룹으로 읽힌다.
    간격만으로 부족할 때 쓰되, 시각적 복잡도를 늘리므로 아껴 쓴다.
justification:
  en: >-
    [Elements] belong together but nothing groups them. Putting them inside one
    bordered region would make the relationship visible without moving anything.
  ko: >-
    [요소들], 이 요소들은 한 그룹이어야 하는데 지금은 묶어 주는 것이 아무것도 없습니다. 테두리 하나로 감싸면 위치를 옮기지 않고도
    관계가 드러납니다.
competencies:
  - visual-hierarchy
