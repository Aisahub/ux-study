---
slug: disabled-state
name:
  en: Disabled state
  ko: 비활성 상태
definition:
  en: >-
    An element that is present but cannot be used right now. It has to look
    unavailable, and where possible say what would make it available. An element
    that looks usable and does nothing reads as a broken product.
  ko: >-
    화면에 있지만 지금은 사용할 수 없는 요소. 사용할 수 없다는 것이 보여야 하고,
    가능하면 무엇을 해야 사용할 수 있는지도 알려야 한다. 눌러도 될 것처럼 보이는데
    아무 반응이 없으면 사용자는 제품이 고장 났다고 판단한다.
justification:
  en: >-
    [Element] is disabled but does not look disabled, so users will click it and
    conclude the product is broken. Dimming it and stating the condition that
    enables it would fix both problems.
  ko: >-
    [요소], 이건 비활성 상태인데 그렇게 보이지 않아서, 사용자는
    눌러본 뒤 제품이 고장 났다고 판단하게 됩니다. 흐리게 처리하면 비활성이라는 것이 보이고, 어떤 조건에서 쓸 수 있는지 함께 알려 주면 사용자가 고장으로 오해하지 않습니다.
competencies:
  - perceived-clickability
source: https://www.nngroup.com/articles/button-states-communicate-interaction/
