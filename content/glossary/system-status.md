---
slug: system-status
name:
  en: Visibility of system status
  ko: 시스템 상태 가시성
definition:
  en: >-
    The interface says what is happening, while it happens. Every action gets an
    acknowledgement, every wait gets a sign that something is under way, and
    every change of state is announced rather than discovered.
  ko: >-
    인터페이스가 지금 무슨 일이 벌어지고 있는지를 그때그때 말해 주는 것. 모든
    동작에는 반응이 있고, 모든 대기에는 진행 중이라는 신호가 있으며, 상태가
    바뀌면 사용자가 알아채기 전에 먼저 알려 준다.
justification:
  en: >-
    After [action], nothing on screen changes for [how long], so the user cannot
    tell whether it worked. Showing [what] while it runs would make the wait
    readable instead of leaving them to guess.
  ko: >-
    [동작] 이후 [얼마 동안] 화면에 아무 변화가 없어서, 사용자는 이게 된 건지
    안 된 건지 알 수 없습니다. 진행되는 동안 [무엇]을 보여 주면, 사용자가
    짐작하는 대신 기다림을 읽을 수 있게 됩니다.
