---
slug: readability
name:
  en: Readability
  ko: 가독성
definition:
  en: >-
    Whether a block of text can be read comfortably from beginning to end. Line
    spacing, line length, letter spacing and size decide it. Text can be
    perfectly legible character by character and still be exhausting in quantity.
  ko: >-
    글 덩어리를 처음부터 끝까지 편하게 읽어나갈 수 있는지를 말한다.
    행간, 한 줄의 길이, 자간, 크기가 이를 결정한다. 글자 하나하나는 또렷해도
    (판독성이 높아도) 양이 많으면 읽기 힘들 수 있다.
justification:
  en: >-
    [Element] is legible character by character but tiring to read as a block —
    the lines are long and set tightly. Widening the line spacing would fix it
    without changing the typeface.
  ko: >-
    [요소], 이건 글자 하나하나는 읽히지만 덩어리로 읽으면 금세
    지칩니다. 줄이 길고 행간이 좁습니다. 서체를 바꾸지 않고 행간만
    넓혀도 나아집니다.
competencies:
  - readability
