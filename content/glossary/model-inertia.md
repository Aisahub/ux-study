---
slug: model-inertia
name:
  en: Mental-model inertia
  ko: 멘탈 모델 관성
definition:
  en: >-
    How reluctantly a model the user already holds gives way. Meeting something
    that contradicts what they believe, a user more often concludes the
    interface is broken than that their belief was wrong.
  ko: >-
    사용자가 이미 가지고 있는 모델이 좀처럼 물러서지 않는 성질. 자기 믿음과
    어긋나는 것을 만난 사용자는 자기 믿음이 틀렸다고 여기기보다 인터페이스가
    고장 났다고 여기는 쪽이 더 많다.
justification:
  en: >-
    [Change] asks the user to give up something they already believe about
    [what]. That belief does not move easily, so expect this to be read as a
    fault in [screen] rather than as something new worth learning.
  ko: >-
    [변경]은 사용자가 [무엇]에 대해 이미 믿고 있던 것을 내려놓으라고 요구합니다.
    그 믿음은 쉽게 움직이지 않으므로, 새로 익힐 만한 것이 아니라 [화면]의
    결함으로 읽힐 것을 각오해야 합니다.
competencies:
  - mental-model-mismatch
source: https://www.nngroup.com/articles/mental-models/
