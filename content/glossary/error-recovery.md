---
slug: error-recovery
name:
  en: Error recovery
  ko: 오류 복구
definition:
  en: >-
    An error message's second job: after naming what went wrong, say what to do
    about it. A message that only reports the problem leaves the user exactly
    where they were stuck, now with a red border.
  ko: >-
    오류 메시지의 두 번째 임무. 무엇이 잘못됐는지 짚은 다음, 그래서 어떻게 하면
    되는지까지 말해 주는 것. 문제만 알려 주는 메시지는 사용자를 막혔던 그 자리에
    그대로 세워 둔다 — 이제 빨간 테두리까지 두른 채로.
justification:
  en: >-
    [Message] says what is wrong but not what to do next, so the user can only
    guess at [what]. Naming the fix in the message itself would get them moving
    again without leaving the page.
  ko: >-
    [메시지]는 무엇이 잘못됐는지는 말하지만 다음에 무엇을 하라는 말이 없어서,
    사용자는 [무엇]을 짐작하는 수밖에 없습니다. 메시지 안에서 해결 방법까지
    알려 주면 페이지를 떠나지 않고도 다시 나아갈 수 있습니다.
competencies:
  - error-handling
source: https://www.nngroup.com/articles/error-message-guidelines/
