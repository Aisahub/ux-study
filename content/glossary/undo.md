---
slug: undo
name:
  en: Undo
  ko: 실행 취소
definition:
  en: >-
    Letting an action be taken back after it has happened. Its real value is
    before the click, not after: a user who knows a thing can be undone will try
    it, and a user who does not will stop and ask someone.
  ko: >-
    이미 일어난 동작을 되돌릴 수 있게 하는 것. 진짜 값어치는 누른 뒤가 아니라
    누르기 전에 있다. 되돌릴 수 있다는 걸 아는 사용자는 일단 해 보고, 모르는
    사용자는 멈춰 서서 누군가에게 물어본다.
justification:
  en: >-
    [Action] cannot be taken back, so it is guarded with [a confirmation dialog
    / nothing at all] instead. Making it undoable would let people try it
    without having to be sure first.
  ko: >-
    [동작], 이건 되돌릴 수 없습니다. 지금 이를 막아 주는 것은
    [확인 대화상자뿐입니다 / 아무것도 없습니다]. 되돌릴 수 있게
    만들면, 미리 확신하지 않고도 일단 해 볼 수 있게 됩니다.
competencies:
  - way-back-and-control
source: https://www.nngroup.com/articles/user-control-and-freedom/
